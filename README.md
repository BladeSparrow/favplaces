# FavPlaces

- Додавайте місця з описом, фото, рейтингом
- Переглядайте список та деталі місць
- Випадковий вибір місця з урахуванням рейтингу
- Всі дані та фото очищаються при кожному запуску сервера

## Запуск

1. Встановіть залежності:
   pip install -r requirements.txt
2. Міграції:
   python manage.py migrate
3. Запуск:
   python manage.py runserver

Сайт буде доступний на http://127.0.0.1:8000/
